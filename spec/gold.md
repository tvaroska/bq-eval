# Gold Add-Ons

> What the optional Evaluation, Monitoring, and Cost add-ons deliver on top of [Silver](silver.md), and the rules they obey.

## Shared rules

1. **Silver views and reference tables only:** Gold add-ons never read raw `spans`, shape adapters, or Bronze sources directly.
2. **Independent add-ons:** Each add-on (Evaluation, Monitoring, Cost) can be deployed on its own and never reaches into another add-on's internal views; only published Gold outputs (such as verified-outcome status for Cost) are shared.
3. **Each add-on defines its own pass:** Silver publishes counts and facts. What counts as completed, slow, looping, or verified is decided here, per add-on and per workload.
4. **In-cloud text & PII boundary:** Any check or judge inspecting `trace_payloads`, raw tool arguments/results, event payload JSON, or raw `user_id` / `tenant_id` reads `silver_restricted` (under BU/tenant RAPs) inside the cloud holding that data and masks direct PII before LLM judge prompts where policy requires; everything else reads `silver_open`.
5. **Preventive vs. detective boundary (`ADR-032`):** BigQuery Gold checks run on a `>= 5m` schedule and audit compliance post-hoc. Synchronous blocking (live write authorization, DLP blocking, allow-list rejection, `1s/10s` `429` shedding, daytime-PT blocking of `optimize`) belongs strictly to the **Preventive Request-Path Enforcement Port** (gateway/proxy), never BigQuery SQL.
6. **SQL first:** Deterministic checks, aggregations, pricing, and calibration math run in BigQuery SQL (in-BigQuery Python stored procedures only where SQL cannot express the math).
7. **Results are kept:** Each add-on reads the explicit Silver time window that covers its question, once that window has settled, and stores daily results alongside the SCD-2 reference snapshots and population counts used.
8. **Sampled applications fail closed:** Gold does not scale an application whose `app_registry.sampling_mode` is `full` (`ADR-043`). Otherwise counts and cost divide by `traces.sampling_probability`; where it is missing the scaled number stays empty (`NULL` never defaults to `1.0`) and the observed number is published beside it. "Never" checks require `app_registry.sampling_mode = 'full'` and zero unexplained missing-sampling rows.
9. **Rootless & orphan-write safety:** Routine baseline metrics skip traces that are not turns or have not settled. A settled trace with a missing parent (`missing_parent_count > 0`) that contains tool calls or `writes_state = true` mutations, routes to an orphaned-activity safety alert; an orphaned server span at the entry of a trace or at a service hop does not — and Gold additionally runs a **reverse `action.committed -> tool_calls` check** to catch committed writes whose tool span was silently dropped at the `65,533 B` OTLP limit.
10. **Concrete slot & PT backpressure circuit-breaker contract (`ADR-031`):** All compaction, evaluation, and judging jobs run in isolated reservations enforcing: (a) per-query `max_bytes_billed` ceilings, (b) pre-flight `INFORMATION_SCHEMA.JOBS` reservation-utilization checks (shedding non-critical `RL-3`–`RL-5` judging and capping tail-sampling fan-out when reservation utilization exceeds threshold or `enterprise` `MERGE` lag breaches budget), and (c) gateway-enforced off-peak/`FLEX` routing so judging never starves production incident-response warehouse slots or daytime PT.

## 1. Evaluation add-on

- **Completed turns, structured guardrail separation & verified outcomes:**
  - A turn (a trace with at least one agent, model-call or tool span) is **completed** when its root span, the first span an application emitted, ended without error and `bq_eval.app_failed` is not true (`ADR-037`). Calls whose content is missing are never scored (`ADR-036`). Safety/policy interventions (`guardrail.intervention` carrying `control_id`, `layer`, `action`: `block | redact | shadow`) are classified separately from `bq_eval.app_failed` crashes, and count as platform-verified only when they sit in a landing place platform controls alone can write.
  - An outcome is **verified** only when every trace completed (or the closing trace where retries are declared expected), deterministic gates pass, traces are settled, `outcome.status = 'succeeded'`, and required semantic/human/authoritative domain checks pass (`outcome.status` also supports `rejected` and `denied`).
  - **PII-Free GCS Object-Lock WORM Gold Audit Snapshots & RTBF (`UC5`, `UC9`, `ADR-031`):** Because BigQuery tables lack native SEC 17a-4 WORM object locks, regulated workloads export immutable snapshots to **GCS Bucket Retention-Lock + CMEK** archives containing `snapshot_id`, `snapshot_time`, `trace_id`/`outcome_id`, `silver_sql_version`, `rubric_version`, `judge_model_version`, `agent_version`, `skill_sha256`, `protected_block_sha256`, `calibration_snapshot_id`, frozen SCD-2 `reference_table_snapshot_json`, `policy_verdicts_json`, input/evidence digests, `args_sha256`/`approved_args_sha256`, optional `sor_signature_ref`, and row-level `snapshot_sha256`. Snapshots contain **zero raw PII or prompt text**; any linked user-level key uses **per-subject crypto-shredding DEKs** so Right-to-Be-Forgotten erasure never violates WORM immutability.
- **Deterministic SQL policy, safety & schema gates (run on 100% of rows before any LLM judge):**
  - **Identity, OBO & cross-tenant isolation:** On `RL-1`–`RL-3` regulated workloads, unattested `user_id` (`identity_attested != true`) fails closed immediately. Which id is the requester when a platform-class span carries a different one is Gold's rule to set, not Silver's (`ADR-034`); it is not set yet ([open-questions.md](open-questions.md)), so today this gate reads the root span's `user_id`. Wherever a rule depends on the tier, an application that is unregistered or whose identity is not bound to its landing place (`app_identity_bound = false`) is treated as the strictest tier (`ADR-040`). Verifies `traces.user_id` / `tenant_id` against target IDs in `tool_calls.arguments` (when `authz_mode = 'parameter_matched'`) or validates structured OBO claims (`auth_method`, `issuer`, `aud`, `delegation_chain_hash` when `authz_mode = 'token_enforced'`).
  - **Information barriers, silent empty-RAG & fiduciary checks (`UC9`, `UC10`):** Verifies retrieved `data_source_id` / tool access against `app_registry.barrier_domain` (MNPI wall checks), flags silent empty-RAG (`acl_dropped_count == retrieved_count` when chunks existed before ACL filtering), verifies `Guide`/`Answer` `state.transition` invariants, and runs deterministic numeric-threshold and prohibited-entity checks against retrieved `turn_context`.
  - **Pre-ticket rejection, sender auth & runbook escalation (`UC2`):** Verifies inbound sender authentication (`DKIM`/`DMARC` metadata where configured), `outcome.rejected` without `outcome.ticket_created` or `creates_ticket` calls plus an external reply, and runbook lookup results vs. `outcome.escalated`.
  - **Sandbox & workspace safety (`UC2`, `UC8`):** Audits `tools.executes_code = true` against call status and `bq_eval.sandbox.status`, blocking failed or unexecuted code from verification; distinguishes local `tools.modifies_workspace = true` edits from regulated SoR `tools.writes_state = true` mutations.
  - **Per-turn PII/secrets & inline verdicts:** Scans `1x` turn deltas (`turn_prompt`, `tool_calls` I/O, `step_outputs`, `turn_output`) when text is stored, and audits structured inline gateway DLP/guardrail verdicts (`guardrail.intervention`). Text not read whole is reported, never passed.
  - **Output schema, citations, disclaimers & authoritative compliance pins:** Validates JSON schemas, disclaimers, URL/corpus-digest citations against `turn_context`, and compares span `protected_block_sha256` against authoritative SCD-2 **`skill_registry`** (failing closed on drift or unregistered skills).
  - **Fail-closed HITL write gates & reverse orphan-commit audit (`UC5`):** Fails closed on unregistered tools on regulated workloads. Matches `tools.writes_state = true` to authoritative `outcome.approved` on `action_id`, RFC 8785 `approved_args_sha256 = args_sha256` (`args_hash_attested = true` or SoR cross-check; a write whose tool-side hash has no source cannot pass), `event_time < tool_calls.start_time <= approved_expires_at`, Maker-Checker SoD (`actor_id != user_id`, plus notional-tiered multi-approver quorums where configured), single-use `event_id`, and authoritative `action.committed` (`committed_args_sha256`). Additionally reconciles **in reverse (`action.committed -> tool_calls`)** to catch writes whose `execute_tool` span was dropped by OTLP size limits, and checks authoritative MRM `model.approved` release events.
  - **Model allow-list & Pre-GA lane enforcement (with [capacity extension](capacity.md)):** Flags any `model_calls` row violating scoped `allowed_models` (`provider`, `model`, `region`, `environment`, `business_unit`, `risk_tier`, `app_id`, `invokable_status`, `zdr_allowed`, `eol_date`), blocks production data on Pre-GA `runtime_lane` endpoints, and enforces `allowed_models.zdr_allowed = true` on Gold judges where the allow-list requires it.
  - **Dark-agent fleet reconciliation (`UC10`):** Flags both unregistered telemetry emitters and cloud-registered agents absent from Silver spans.
- **Stateful session reconstruction & sampled 4-point ordinal LLM judging:**
  - For stateful `previous_interaction_id` delta turns on `regulated_worm` / `ephemeral_sample` workloads, Gold reconstructs prior turns `1..k-1` and memory-mutation state over a bounded lookback window into `<untrusted_text>` before judging — failing closed with `MISSING_SESSION_CONTEXT` if prior state is unavailable (`ADR-033`).
  - Routine quality judging skips turns failing deterministic gates, sampling `5–10%` of passing baseline turns plus `100%` of slow, throttled, escalated, low-confidence, or `thumbs_down` strata. **Guardrail FP/FN audit (`UC9`):** runs separate stratified false-positive judging on a sample of `guardrail.intervention` (`action = 'block'`) turns and false-negative spot audits on passing turns.
  - Escapes `&`, `<`, and `>` in `<untrusted_text>`, masks direct client PII where required, passes in-place `media_uris`, pins deterministic judge execution (`temperature = 0`, explicit `seed`, immutable `judge_model_snapshot_id`, `judge_prompt_sha256`, and independent judge-model family from the evaluated model), emits reasoning before a 4-point ordinal score (`>= 3` passes), and aligns export structure with `ATIF-v1.8` / `AI.EVALUATE_AGENT` (preview) conventions.
- **Stratified `SR 11-7` calibration, binary cut-point agreement & expanded expiry (`ADR-033`):**
  - Computes **stratum-specific** Rogan-Gladen conditional prevalence ($\hat{\theta}_{\text{RG}}$ using stratum-level $Se_h, Sp_h$ rather than assuming constant $Se/Sp$ across oversampled tails, with per-cloud $Se/Sp$ when multi-cloud judges differ), unconditional end-to-end prevalence ($\hat{P}(\text{Det}) \times \hat{\theta}_{\text{RG}}$) with design-based joint 95% confidence-interval propagation and $[0,1]$ boundary clamping, **dual-blind `SME-vs-SME AC2`** and **`judge-vs-SME AC2` (`>= 0.80`) paired with binary pass/fail cut-point agreement** (preventing quadratic partial credit from masking `2`-vs-`3` threshold flips), explicit SME tie-break adjudication, and confidence calibration (ECE) on auto-accepted strata (`UC4`).
  - Enforces **risk-tiered minimum sample floors** (standard default `>= 10` judged / `>= 5` pos & `>= 5` neg; regulated **`RL-1` default `>= 100` judged**) and invalidates `CALIBRATED` (`STALE_CALIBRATION`) on TTL expiry or whenever any of `judge_model_snapshot_id`, `judge_prompt_sha256`, `rubric_version`, `model`, `agent_version`, `skill_sha256`, `system_instructions`, `tool_definitions_sha256`, or `corpus_digest` changes. Reports `NULL` (`UNJUDGED`, `UNCALIBRATED`, `STALE_CALIBRATION`, or `MISSING_SESSION_CONTEXT`) whenever gates fail or $J / J' \le 10^{-6}$.
- **Paired regression, live A/B migrations, delayed truth, `< 5s` Local/CI Runner & Optimizer Gold Export Port:**
  - Supports paired candidate-vs-baseline evaluation on `bq_eval.case_id` (offline/CI) **and** live interactive A/B migrations on `shadow_of_trace_id` / `experiment_id` / `variant_id` (`UC3`), enforcing `0.0%` negative flips on regulated/safety gates (`UC5`), cohort/demographic parity checks (`< 2%` delta, `UC9`), authoritative CI/SAST verification (`UC8`), delayed external ground-truth reconciliation (`T+1` conversion matching in `UC6`; `T+7d..30d` `postmortem.verified` reconciliation in `UC7`), and cascade total-cost vs. calibrated accuracy floor (`UC4`).
  - Exposes the **`< 5s` Local/CI Eval Runner Port** (`CI_ONLY`) running Silver SQL + deterministic `Rule 0` + composite scorers offline for DevAI PR merge gates (`UC8`) and 400–800-rollout optimizer sweeps (`UC6`), never conflated with SME-calibrated production scores.
  - Publishes the versioned **Optimizer Gold Export Port** (`UC6`) with fixed columns: `eval_run_id`, `candidate_id`, `optimizer_mode`, `skill_sha256`, `protected_block_sha256` (verified against `skill_registry`), `mounted_skills`, `eval_split` (`train | holdout` with enforced `case_id` disjointness), `nudge_id`, `CI_ONLY` Pareto composite score, calibrated holdout pass rate, and prefix-cache floor checks evaluated against SKU `min_cache_tokens`.

## 2. Monitoring add-on

- **SLA & missing-identity monitoring:** SLA clocks start at `traces.trace_start_time`, the earliest stored span of the trace, whoever wrote it (`ADR-037`); starting the trace when the request arrives stays an application duty. Computes acknowledgement/rejection and net resolution times (minus customer wait from `events`) across open and closed `outcomes`. Checks root-span traces for missing requesters on a `>= 5m` schedule (sub-minute blocking lives in the Preventive Request-Path Enforcement Port).
- **Latency, first-token time & throttling:** Tracks end-to-end turn latency, per-call latency, `429` throttling, and turn-level TTFT from `traces` and `model_calls`.
- **Settled traces & cross-cloud skew:** A trace is settled when its last span arrived longer ago than the settle setting (and, in multi-cloud mode, no spoke Hub Transfer lag watermark is pending).
- **Workload loop, dynamic-tool churn & retry budgets:** Evaluates per-app tool-call caps, repeated identical tool calls (the repeat number per trace in `tool_calls_open`; across an outcome, counted from the restricted views), edit-test/query/sandbox retry oscillations, and per-turn `tool_definitions_sha256` churn alerts.
- **Bounded session, prefix-cache & feedback diagnostics:** Computes bounded Gold session rollups over `gen_ai.conversation.id` (turn count, cumulative context growth, **`thought_signature_present` read directly from core `model_calls`**, and prefix-cache hit-rate cliffs) and tracks per-`nudge_id` `feedback.thumbs_up` / `feedback.thumbs_down` with `feedback_reason` and conversion rates (with click-rate bias awareness).

## 3. Cost add-on & `capacity` export contract

- **Per-call pricing across six spend buckets (incl. embeddings, sandbox & reconciled warehouse compute):** Prices each `model_calls` row (LLM inference and `embeddings`) against the Gold SKU catalog (`>200K` 1P/3P cliffs keyed on total context `input_tokens + cache_read_tokens`, `FLEX`, 3P tier weights, and `min_cache_tokens`; cache-write splits by lifetime come only from the gateway's request records), adds container/sandbox compute (`sandbox.cpu_sec` + `sandbox.mem_gb_sec`) and downstream warehouse query compute (**reconciled against `INFORMATION_SCHEMA.JOBS` via `db.query.job_id` / `bytes_billed`**, falling back to tool-span metrics only when unlinked and flagged), plus vector-search/memory-store attribution where emitted, across `production_inference`, `conflict_escalation`, `agent_gym_eval`, `autorater_judge`, `optimize`, and `unclassified`.
- **Outcome, M:N, cascade, specialist & user attribution:** Computes `CPVO` keeping failed, rejected, denied, and escalated attempts plus `100%` of judge runs and downstream compute in the numerator; allocates M:N linked incident spend via `outcome_links` (`1 / COUNT(linked_outcomes)` default or explicit weight); slices by specialist agent, PDF page band, escalation reason, `FLEX`-vs-idle-PT arbitrage (`UC4`), and user/org-unit (via deployment directory join).
- **`capacity` export (`ADR-001` boundary preserved):** Publishes versioned hourly chargeback/burndown and `burst_metrics_1m` payloads consumed by the sibling `capacity` repository (which computes Newsvendor sizing and gateway shedding policies — never merged into `bq-eval`).
- **With the [capacity extension](capacity.md):** Prices **each upstream `requests` attempt individually first** (joined on `x-client-request-id` + `(trace_id, span_id)`) before collapsing per call, computes explicit **3-pool `FOCUS 1.2` spillover & invoice reconciliation** (active funded PT, off-peak backfill, unallocated idle PT, `1.8x` Priority PayGo spillover, and Standard PayGo reconciled against Cloud Billing invoice/RVP exports), attributes mixed `FIXED_TERM` vs. `AUTO_RENEW` `order_id`s pro-rata inside shared FCFS `runtime_pool_id` buckets, flags `eval`/`optimize` hitting daytime `RL-1`/`RL-2` PT pools, separates `gateway_failover_attempts` from `caller_retry_count` SDK retry storms, and attributes `embeddings` pools alongside LLM pools.
