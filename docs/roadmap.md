# Roadmap (`bq-eval`)

## Where we are

`bq-eval` `v0.2.3` ships a zero-debt (`67` tests, `mypy --strict` across `23` source files, `ast-grep` `Rule 0` firewall, `6/6` SQL/FinOps mutants killed) Dual-Path BigQuery SQL and offline SQLite evaluation and FinOps engine over Light Capture (`BQAA` `agent_events`) and Full Capture (`OTel` `_AllSpans`), validated on `343` live multi-agent runs (`m2-live-20261113b`). `M6` (`v0.2.3`) closed `StratPPI` tail-sampling debiasing, SQLite multi-app/SME/outcome parity, `eval_results` deduplication, Engine B token/pricing quota accounting, `EVAL-P10` rubrics + fail-closed `EVAL.yaml`, pricing catalog seeding (`F1`), temporal paired-run ordering (`F2`), and `F3`–`F6`, `F8`–`F10`, `F15`, `F16`, `F19`, `F20`. Two showcase-graduation milestone tracks remain: (1) a `.stitch/DESIGN.md`-governed GM3 Light `bq-eval serve` workbench backed by committed empirical receipts, verified `capacity`/`docubridge` wire contracts, and daily-review items `F7`, `F11`–`F14`, `F17`, `F18`, `F21` (`M7` / `v0.3.0`); and (2) one-command standalone BigQuery/Terraform bootstrap code targeting a single co-located `Showcases` GCP project alongside `docubridge` and `docubridge-examples`, held ready locally without deploying yet (`M8` / `v0.4.0`).
