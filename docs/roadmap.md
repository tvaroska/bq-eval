## M16 — Live BigQuery Deployment & Unconfounded Cloud Proof (`v0.5.0`)

- [ ] **M16-1 (`S-5`, `S-15`): Execute live GCP bootstrap, `terraform apply`, and concurrency/alias checks** — Apply [`terraform/`](../terraform/main.tf) on the target GCP project (after explicit operator sign-off), deploy via `bq-eval bootstrap --mode full`, run a live two-call concurrent `CALL agent_eval.run_daily_quota_guarded_judge(...)` lock verification (`S-5`), and dry-run/create the `GROUP BY outcome_id` and `trace_id`-shadowing views (`S-15`: [`sql/core/step1_trace_views.sql`](../sql/core/step1_trace_views.sql), [`sql/core/bqaa_adapter_views.sql`](../sql/core/bqaa_adapter_views.sql)), renaming aliases if BigQuery rejects them. Done when all live views create cleanly and the concurrent `CALL` check commits zero overspend.
- [ ] **M16-2 (`M10-3a`): Capture unconfounded `>200K` arms, App Hub joins, and live `INFORMATION_SCHEMA.JOBS` CPVO** — Run live single-model `<=200K` vs. `>200K` benchmark arms (`N >= 30`/arm, validated with [`scripts/empirical_proof.py`](../scripts/empirical_proof.py)), collect anonymized raw trace exports (`N >= 100`) and live App Hub ownership join receipts, fold live `INFORMATION_SCHEMA.JOBS` query cost into `bq_query_jobs` and `CPVO`, and release `v0.5.0`. Done when `scripts/empirical_proof.py` passes on live exports with zero confounded models and receipts are committed.

## M17 — Blind Dual-Human SME Calibration & Final `L3` Proof Refresh (`v0.6.0`)

- [ ] **M17-1 (`M10-3b`): Collect and validate blind dual-human `sme_labels` (`N >= 100`)** — Collect `N >= 100` blind dual-human SME annotations (`>= 2` human raters/case) on live traces, validate human-vs-human and human-vs-LLM `AC2` via [`scripts/empirical_proof.py`](../scripts/empirical_proof.py) (replacing the `0`-human-label Flash-vs-Argon proxy), and commit sanitized calibration receipts. Done when `validate_blind_dual_human_labels()` exits clean on `N >= 100` blind human cases.
- [ ] **M17-2 (`M10-3c`): Refresh `README.md` / `docs/results.md` and release `v0.6.0`** — Update [`README.md`](../README.md) (preserving locked `L1`/`L2`) and [`docs/results.md`](results.md) with human-calibrated accuracy and unconfounded `>200K` receipts, confirm `/showcase-panel` reaches `S-Score >= 70 A`, and tag `v0.6.0`.
