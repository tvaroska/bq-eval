# Roadmap (`bq-eval`)

## Where we are

`bq-eval` `v0.3.0` (`M7`) delivers a zero-debt (`111` tests, `mypy --strict`, `ast-grep` layered `Rule 0` firewall, `standards_debt.json = 0`) Dual-Path BigQuery SQL and offline SQLite evaluation and FinOps engine over Light Capture (`BQAA` `agent_events`) and Full Capture (`OTel` `_AllSpans`), backed by a `.stitch/DESIGN.md`-governed 4-tab GM3 Light workbench (`bq-eval serve`), committed sanitized `343`-run empirical receipts (`benchmarks/results/m2_live_receipt.json` + SHA-256 manifest), verified `capacity` and `docubridge` wire contracts, layered `bq_eval/{contract,engine,showcase,cli}/` subpackages, and closure of all `M7` daily-review items (`F7`, `F11`–`F14`, `F17`, `F18`, `F21`). One showcase-graduation milestone remains: one-command standalone BigQuery/Terraform bootstrap code targeting a single co-located `Showcases` GCP project alongside `docubridge` and `docubridge-examples`, held ready locally without deploying yet (`M8` / `v0.4.0`).
